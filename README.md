# VisionGuard AI

AI-powered smart compliance monitoring system for food safety.

## Overview

VisionGuard AI uses Computer Vision and AI to monitor surveillance camera footage and detect selected food safety violations.

## MVP Violations

- Smoking in restricted areas
- Not wearing a hair net
- Not wearing protective gloves

## Technologies

- Artificial Intelligence
- Machine Learning
- Computer Vision
- Web Development
